# Photography Admin Panel

This is the backend admin interface for managing the photo gallery, uploading images, and moderating content.

## 💻 Built With
- HTML
- CSS
- PHP

## 🚀 Features
- Secure login
- Upload new photos
- Edit/delete existing content
- View usage statistics (if any)
